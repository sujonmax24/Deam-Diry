# 📔 Deam-Diry (আমার ডায়রি)

**Write Your Dream Every Time, Every Place.**

Deam-Diry হলো একটি আধুনিক এবং সুন্দর অ্যান্ড্রয়েড নোটবুক অ্যাপ, যা আপনার ব্যক্তিগত ডায়রি বা নোট সংরক্ষণ করার জন্য ডিজাইন করা হয়েছে। এটি Jetpack Compose এবং Material Design 3 ব্যবহার করে তৈরি।

---

## ✨ ফিচারসমূহ

- 📖 **ডায়রি স্টাইল ইন্টারফেস:** পেজ সোয়াইপ করে নোট পড়ার অভিজ্ঞতা।
-  **পাসওয়ার্ড প্রোটেকশন:** আপনার নোটগুলো সম্পূর্ণ নিরাপদ।
- 📁 **ফোল্ডার সাপোর্ট:** নোটগুলোকে আলাদা ফোল্ডারে গুছিয়ে রাখুন।
- 🗑️ **রিসাইকেল বিন:** ভুলে ডিলেট করা নোট পুনরুদ্ধার করুন।
-  **নোট লুকানো:** গোপনীয় নোট লুকিয়ে রাখার সুবিধা।
- ⚙️ **কাস্টম সেটিংস:** 
  - ☀️ স্ক্রিনের ব্রাইটনেস নিয়ন্ত্রণ।
  - 🔤 ফন্টের সাইজ ছোট-বড় করা।
-  **ছবি সংযুক্ত করা:** নোটের সাথে ছবি যোগ করুন।
- 🌙 **ডার্ক/লাইট থিম:** সুন্দর ডায়রি কালার থিম।

---

## 🛠️ টেকনোলজি

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Database:** Room Database
- **Image Loading:** Coil
- **Architecture:** MVVM (Model-View-ViewModel)
- **Build System:** Gradle (Kotlin DSL)
